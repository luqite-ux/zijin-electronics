# Zijin Electronics Website

Premium English B2B inquiry website for Yueqing Zijin Electronics Co., Ltd.

## Scope

- English single-language frontend with data structure ready for future language expansion.
- Independent pages for Home, About, Products, Product Detail, Manufacturing, Quality & Certifications, FAQ, and Contact.
- 19 product categories and 618 product models scraped from the original Zijin product catalog link.
- No retail purchase flow or public commercial terms.
- All product and CTA paths lead to the real inquiry form.

## Scripts

```bash
pnpm install
pnpm test
pnpm build
pnpm dev
```
